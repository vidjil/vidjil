## Tracability

Vidjil offer the possibility to trace every actions made by users. 

In the log tab, you can find a table summarizing all the actions performed by Vidjil users.

This table has the following columns:

- User: The user who performed the action
- Table: The type of data affected
- Message: Description of the action performed
- Name:
- Created: The date and time of the action

As a standard user, the log tab only display treacability linked to your current groups

As an admin, the log tab display the traceability data of all Vidjil users

All the actions are stored in Vidjil database.
